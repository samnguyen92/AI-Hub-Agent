# Search Console Analysis Skill

## Nhận diện Cơ hội Tối ưu (Quick Wins)
1. **Low CTR Opportunities**:
   - Các từ khóa / trang có `Impressions > 500` và `Position <= 10` nhưng `CTR < 3%`.
   - *Hành động*: Viết lại Thẻ Title và Meta Description hấp dẫn hơn, bổ sung con số hoặc ưu đãi.
2. **Striking Distance Keywords**:
   - Từ khóa xếp hạng ở trang 2 (vị trí `11 - 20`).
   - *Hành động*: Cập nhật thêm nội dung chuyên sâu, internal linking từ các trang có PR cao để đẩy vào Top 10.
3. **Index Coverage Issues**:
   - Phân loại lỗi `Crawled - currently not indexed` hoặc `Discovered - currently not indexed`.
