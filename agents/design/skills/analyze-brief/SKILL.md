# Analyze Brief Skill

## Mục đích
Giúp Design Agent bóc tách và hiểu sâu sắc yêu cầu của người dùng trước khi tiến hành viết code HTML/CSS mockup.

## Các bước thực hiện
1. **Xác định mục tiêu chính (Goal)**: Trang landing page giới thiệu, SaaS Dashboard, trang thương mại điện tử, hay Portfolio cá nhân?
2. **Đối tượng sử dụng (Target Audience)**: Doanh nghiệp B2B, người dùng phổ thông B2C, lập trình viên, hay nhà thiết kế?
3. **Cấu trúc trang (Information Architecture)**:
   - Header / Navigation: Logo, links, CTA button.
   - Hero Section: Headline hấp dẫn, subheadline, CTA, hình ảnh hoặc mockup trực quan.
   - Social Proof / Features / Benefits: Điểm nổi bật, giải pháp giải quyết vấn đề.
   - Testimonials / Pricing (nếu có).
   - Footer: Bản quyền, links điều hướng, mạng xã hội.
4. **Kiểm tra độ đầy đủ thông tin**:
   - Nếu yêu cầu người dùng thiếu định hướng rõ rệt (ví dụ chỉ nói "hãy thiết kế web"), hãy dùng tool `request_input` để hỏi nhanh tone-and-mood hoặc các sections mong muốn.
